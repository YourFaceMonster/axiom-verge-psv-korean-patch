# Axiom Verge PS Vita 한글패치 — 전체 번역 베타

미국판 **PCSE00651**의 English 텍스트를 PC판 한글패치 v1.1을 바탕으로 한글화한 베타입니다. 메뉴뿐 아니라 아이템, 노트, 전체 대사, 인트로, 꿈, 엔딩과 제작진 표제를 포함합니다.

실기로 확인한 항목은 아래 검증 상태에 정리했습니다. 전체 플레이 검증은 아직 완료되지 않았습니다.

## 다운로드

[복사 설치용 rePatch ZIP 다운로드](https://github.com/YourFaceMonster/axiom-verge-psv-korean-patch/releases/latest)

## 설치 방법

대상은 미국판 **PCSE00651**이며, rePatch가 활성화되어 있어야 합니다. 다른 지역판과 업데이트 버전은 지원을 확인하지 않았습니다.

1. 게임을 완전히 종료합니다.
2. 기존 `ux0:rePatch/PCSE00651` 폴더가 있으면 전체를 별도 위치에 백업합니다.
3. ZIP을 압축 해제하고, 안의 **rePatch 폴더를 PSV의 ux0: 최상위에 복사**합니다. 기존 파일은 덮어씁니다.
4. 복사 후 `ux0:rePatch/PCSE00651/eboot.bin`과 `ux0:rePatch/PCSE00651/Content`가 있는지 확인합니다.
5. 게임 언어 **English**로 실행합니다. 기존 세이브를 유지해도 됩니다.

ZIP에 설치에 필요한 파일이 모두 포함되어 있습니다. 실행 파일을 따로 패치하거나 파이썬을 실행할 필요가 없습니다. **eboot.bin과 Content를 함께 복사하세요.**

## 검증 상태

실기에서 다음 항목을 확인했습니다.

- 시작 / 설정 / 스피드런 표시 및 동작
- 세이브 불러오기 화면
- 일시정지와 스킵 확인창
- 예 / 아니오 표시
- 초반 트레이스 대사 표시

전체 플레이 검증은 아직 완료되지 않았습니다.

## 문제 제보

문제가 발생한 장면/메뉴, 문구, 사진, 지역판과 업데이트 적용 여부를 함께 남겨주세요. 글자 누락, 물음표, 겹침, 잘림 또는 진행 중단을 확인하면 도움이 됩니다.

## 복구

게임을 종료하고 현재 패치의 `ux0:rePatch/PCSE00651` 폴더를 별도 위치로 옮긴 뒤 백업한 폴더 전체를 복원합니다. 실행 파일·XML·글꼴을 함께 복원하세요. 게임 원본 app 폴더와 세이브는 수정하지 않습니다.
